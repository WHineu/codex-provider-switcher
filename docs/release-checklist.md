# Release Checklist

- [ ] License and copyright attribution reviewed by the owner.
- [ ] Repository name and maintainer contact confirmed.
- [ ] Unit and lifecycle tests pass on a clean macOS environment.
- [ ] App builds, launches, lists providers, switches, and rolls back safely.
- [ ] No real provider configuration, credentials, task IDs, or personal paths.
- [ ] No compiled cache or local log files are tracked.
- [ ] Third-party names appear only in compatibility documentation when needed.
- [ ] Non-affiliation and third-party terms boundary is clear.
- [ ] Public binary signing/notarization policy is decided.
- [ ] Security reporting is enabled before announcing the repository.
- [ ] Public repository creation, initial commit, and push are explicitly approved.
